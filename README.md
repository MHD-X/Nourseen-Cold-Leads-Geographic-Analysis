# 🌍 Nourseen Cold Leads Geographic Analysis (2026)

## 📌 Project Overview
This project provides a comprehensive **Geographic Analysis** of a large-scale student leads database for **Nourseen Center (2026 Archive)**. The dataset contains over **28,000 lead records**. The primary goal was to clean the raw data, process international dial codes, and visualize the density of potential clients to empower the marketing team with data-driven insights.

## 📈 Strategic Key Insights

Based on the interactive analysis, several critical geographic clusters were identified for marketing prioritization:

* **Primary High-Density Market:** **Sudan** is the dominant market, representing the overwhelming majority of leads with over **23,639 leads**. This area should be the top priority for immediate engagement.
* **Key Secondary Markets:** Strong regional clusters are emerging in:
  * **Saudi Arabia (KSA):** **1,418 leads**
  * **Egypt (EGY):** **1,293 leads**
* **Growth Opportunities:** Moderate densities observed across other GCC countries (UAE, Qatar, Kuwait), Chad, and North Africa (Morocco, Iraq), offering valuable expansion targets.
